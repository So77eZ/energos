# CLAUDE.md

## Git

- Ветки называть осмысленно, по сути изменения: `<тип>/<kebab-case-слаг>`, где тип — `feat`, `fix`, `docs`, `test`, `refactor`, `chore`. Пример: `feat/graceful-401`. Автосгенерированные имена (`claude/zen-goldberg-e5ewsn` и т.п.) не использовать.
- `main` защищён — изменения только через PR.
